# 有限会社北陸石油物流 コーポレートサイト

富山県高岡市の道路貨物運送会社「有限会社北陸石油物流」のウェブサイトです。
HTML / CSS / JavaScript のみで作られており、GitHub Pages でそのまま公開できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（私たちについて／事業内容／安全への取り組み／会社概要／事業所／採用／お問い合わせ） |
| `recruit.html` | 採用情報ページ（募集要項） |
| `privacy.html` | 個人情報保護方針 |
| `assets/style.css` | デザイン（配色・レイアウト・スマホ対応） |
| `assets/script.js` | メニュー開閉・スクロール表示 |

## 公開後に差し替えが必要な項目

サイト内に `※` から始まる注記を入れてあります。以下を実際の情報に書き換えてください。

- 電話番号・FAX番号（現在は仮の `0766-00-0000`）
- メールアドレス（現在は仮の `info@example.com`）
- 代表者名
- 資本金・従業員数
- 採用ページの勤務時間・休日・給与・諸手当
- 個人情報保護方針の制定日
- 加入団体（あれば）

## 写真の差し替え

現在はイラスト（SVG）を使っています。写真に差し替える場合は、HTML内の
`【写真差し替え位置】` というコメントの箇所を `<img src="assets/photo.jpg" alt="説明">` に
置き換えてください。画像ファイルは `assets/` フォルダに入れます。

## ローカルでの表示確認

`index.html` をダブルクリックしてブラウザで開けば確認できます。
